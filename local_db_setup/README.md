# Local Database Setup
## SQLite
- sqlite3 is inbuilt into macos. We will use that for this example and proceed
- Run `setup_db.py` to create the database.
- You should get an output like below
    ```bash
    --- Current Data ---
    ID: 1 | NUM: 0 | SQUARE: 0
    ID: 2 | NUM: 1 | SQUARE: 1
    ID: 3 | NUM: 2 | SQUARE: 4
    ID: 4 | NUM: 3 | SQUARE: 9
    ID: 5 | NUM: 4 | SQUARE: 16
    ```
